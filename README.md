# 🌾 สมาร์ทกรีน Vision Ai วิเคราะห์ใบข้าว

ถ่ายภาพใบข้าว 3 ตำแหน่ง (+ กอข้าว / รวง ไม่บังคับ) ให้ AI (Gemini) ช่วยประเมิน
- **ธาตุอาหาร 8 ธาตุ**: N, P, K, Mg, S, Zn, Si, Fe
- **โรคและแมลง**: โรคไหม้, ขอบใบแห้ง, ใบจุดสีน้ำตาล, กาบใบแห้ง, ใบหงิก/เขียวเตี้ย, เพลี้ยกระโดดสีน้ำตาล, หนอนห่อใบ, หนอนกอ, แมลงบั่ว ฯลฯ
- **แผนปุ๋ย** ต่อไร่ตามอายุและชนิดดิน และสิ่งที่ควรทำทันที

เว็บ: https://smartgreen-vision-rice.vercel.app · หน้าแรกรวมพืช: https://smartgreen-vision-ai-home.vercel.app

> ⚠️ ความรู้อ้างอิงและสูตรปุ๋ยในคำสั่ง AI (`lib/riceService.js`) เป็น **ร่าง** จากหลักวิชาการทั่วไป
> ต้องให้ทีมนักวิชาการสมาร์ทกรีนตรวจทานก่อนเปิดใช้กับลูกค้า

## ตำแหน่งภาพ

| ช่อง | ตำแหน่ง | ใช้ดู |
| --- | --- | --- |
| `young` | ใบอ่อน / ใบยอด | Zn, S, Fe · โรคไหม้ · หนอนห่อใบ |
| `mature` | ใบมาตรฐาน | N, P, K (ตัวแทนทั้งกอ) |
| `old` | ใบล่าง / ใบแก่ | N, K, Mg · ใบจุดสีน้ำตาล · ขอบใบแห้ง |
| `tree` (ไม่บังคับ) | กอข้าว / รวง | เพลี้ยกระโดด · หนอนกอ · เมล็ดด่าง |

## โครงสร้าง

| ส่วน | หน้าที่ |
| --- | --- |
| `public/` | หน้าเว็บ: `index.html` (ตรวจใบ), `report.html` (ใบรายงาน A4 + บันทึกรูป), `js/`, `css/`, `assets/` |
| `api/analyze.js` | ฟังก์ชัน Vercel: รับภาพ → `lib/riceService.js` |
| `api/save-sheet.js` | บันทึกผลลง Google Sheets (`lib/sheets.js`, `gas/Code.gs`) |
| `lib/riceService.js` | คำสั่ง AI, ตรวจภาพก่อนวิเคราะห์, จัดรูปผล |
| `lib/riceProducts.js` | ผลิตภัณฑ์สมาร์ทกรีนที่อนุญาตให้ AI แนะนำ (ตอนนี้ว่าง รอฝ่ายวิชาการ) |
| `lib/gemini.js`, `lib/modelRetry.js` | เรียก Gemini พร้อมลองใหม่อัตโนมัติเมื่อระบบหนาแน่น |
| `server.js` | เปิดเว็บทดสอบในเครื่อง http://localhost:8080 |

## ตั้งค่า Vercel (Environment Variables)

| ชื่อ | ค่า |
| --- | --- |
| `GEMINI_API_KEY` | คีย์ Gemini (ใช้ตัวเดียวกับแอปอ้อย/ปาล์มได้) |
| `GOOGLE_SHEETS_WEBHOOK_URL` | (ไม่บังคับ) URL เว็บแอปจาก `gas/Code.gs` ของชีตข้าว |

## รันในเครื่อง

```bash
cp .env.example .env   # ใส่ GEMINI_API_KEY
npm install
npm start
```

## เพิ่มผลิตภัณฑ์สมาร์ทกรีน
แก้ `lib/riceProducts.js` ตามตัวอย่างในไฟล์ และวางรูปสินค้าไว้ที่ `public/assets/`
